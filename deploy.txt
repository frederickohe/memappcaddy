Ymca Member App VPS deploy flow
================================

Server layout (/var/www):
  memapp-backend/
  memappcaddy/       ← run setup scripts from here
  memapp-web/        ← React website + admin (build output in dist/)

Prerequisites
-------------
- Docker + Docker Compose installed
- DNS A records for all hosts → VPS public IP:
    ymemberapp.com, www, api, admin, db, portainer
- Ports 80 and 443 open on the firewall

One-time setup
--------------
cd /var/www/memappcaddy
chmod +x setup-networks.sh setup-ssl.sh
./setup-networks.sh

Deploy / update stacks
----------------------
cd /var/www/memapp-backend
git pull
docker compose down
docker compose up --build -d

cd /var/www/memappcaddy
git pull
docker compose up -d

Issue / refresh TLS certificates
----------------------------------
cd /var/www/memappcaddy
./setup-ssl.sh

Full first-time deploy (after git pull in both repos)
-----------------------------------------------------
cd /var/www/memappcaddy
./setup-networks.sh
cd ../memapp-backend && docker compose up --build -d
cd ../memappcaddy && docker compose up -d
./setup-ssl.sh

Verify
------
https://ymemberapp.com
https://admin.ymemberapp.com
https://api.ymemberapp.com
https://db.ymemberapp.com
https://portainer.ymemberapp.com

CI/CD (GitHub Actions)
----------------------
Backend and admin portal deploy from GitHub Actions on push to `main`.

  memapp-backend  → syntax check, upload source, docker compose up --build
  memapp-web      → production build, upload dist/, restart Caddy
                    (serves ymemberapp.com and admin.ymemberapp.com)

Pull requests only run CI. Production deploys also run a public health check.

One-time GitHub secrets (both repos):
  DEPLOY_HOST     = 62.171.136.252
  DEPLOY_USER     = deploy
  DEPLOY_SSH_KEY  = private key that can SSH as that user

On the VPS as root (once):
  bash /var/www/memappcaddy/scripts/setup-server-for-cicd.sh

On your machine (macOS/Linux):
  gh auth login
  bash memapp-backend/scripts/setup-github-secrets.sh

Then push to main, or run "CI and deploy" from the Actions tab.

Manual deploy on server:
  bash /var/www/memapp-backend/scripts/deploy.sh
  bash /var/www/memapp-web/scripts/deploy.sh
  bash /var/www/memappcaddy/scripts/deploy.sh
